# Changelog

Усі помітні зміни в проєкті **SIPLToolkit** задокументовано в цьому файлі.

## [0.1.0] - 2026-11-17

### Додано
- **Sipl.Core**: моделі AST-вузлів (`ProgramNode`, оператори, арифметичні та булеві вирази), позиціонування `SourceSpan` та структура `Diagnostic`.
- **Sipl.Parser**: лексичний аналізатор (`Lexer`), рекурсивний низхідний парсер (`Parser`) та фасад безпечного аналізу `SiplAnalyzer`.
- **Sipl.Interpreter**: покроковий інтерпретатор мови SIPL із підтримкою подій трасування (`OnTrace`) та захистом від нескінченних циклів.
- **Sipl.Cli**: консольна утиліта з підтримкою команд `parse`, `check`, `run`, `trace` та структурованого виводу `--json`.
- **Sipl.LanguageServer & vscode-sipl**: LSP-сервер на базі OmniSharp та клієнтське розширення для VS Code (діагностика в реальному часі, підказки `Hover`, автодоповнення `Completion`, символи документа `Outline` та семантична підсвітка).
- **Sipl.Tests**: набір модульних та інтеграційних тестів (позитивні/негативні кейси граматики, перевірка інтерпретатора, ліміту ітерацій та JSON-RPC протоколу LSP).
- **CI/CD**: автоматизована збірка, запуск тестів та пакування `.vsix` у GitHub Actions із публікацією у GitHub Releases.
